# 如何设置机器人零位

## 📋 概述

机器人的零位（参考位置）存储在 `config.yaml` 文件的 `ref_joint_act` 参数中。这个参数定义了机器人的"站立姿态"，是RL控制器的参考基准。

## 🔧 方法一：从程序输出中获取（推荐）

### 步骤：

1. **启动程序并调整机器人姿态**
   ```bash
   ./start_qmini_进程.sh
   ```
   或者直接运行：
   ```bash
   ./install/x86_64/bin/run_interface
   ```

2. **手动调整机器人到想要的零位姿态**
   - 确保机器人处于稳定、平衡的站立姿态
   - 这是你希望作为"零位"的姿态

3. **查看程序输出的关节位置**
   - 程序每2.25秒（150个控制周期）会打印一次当前关节位置
   - 输出格式：`Q: [ 0.12, -0.35, -0.42, ... ]`

4. **复制关节位置并更新config.yaml**
   - 从输出中复制关节位置数组
   - 打开 `config.yaml` 文件
   - 找到 `ref_joint_act` 行（约第23行）
   - 替换为新的关节位置值

   **示例**：
   ```yaml
   # 原来的值
   ref_joint_act: [ -0.09, -0.37, -0.43, -0.50, -0.10, -0.28, 0.15, 0.07, 0.35, 0.05 ]
   
   # 替换为新的值（从程序输出复制）
   ref_joint_act: [ 0.12, -0.35, -0.42, -0.48, -0.11, -0.27, 0.16, 0.08, 0.34, 0.06 ]
   ```

5. **重启程序使配置生效**
   ```bash
   ./stop_qmini_进程.sh
   ./start_qmini_进程.sh
   ```

## 🔧 方法二：使用代码中的辅助函数

### 步骤：

1. **在代码中调用打印函数**
   
   在 `src/user/custom.cpp` 的 `Control()` 函数中，可以添加调用：
   ```cpp
   // 在需要的时候调用（比如按某个键时）
   PrintCurrentJointPositionAsZero();
   ```

2. **或者创建一个测试程序**
   
   可以创建一个简单的测试程序来读取当前关节位置并打印。

## 📝 关节位置说明

- **关节数量**：Qmini有10个关节
- **单位**：弧度（rad）
- **顺序**：按照关节索引顺序排列

### 关节索引对应关系：
```
索引 0-4:  左腿关节（髋关节、膝关节等）
索引 5-9:  右腿关节（髋关节、膝关节等）
```

## ⚠️ 注意事项

1. **确保机器人稳定**：在记录零位时，确保机器人处于稳定、平衡的状态

2. **检查关节限制**：确保零位位置在关节限制范围内（`act_pos_low` 和 `act_pos_high`）

3. **备份原配置**：修改前建议备份 `config.yaml` 文件

4. **精度建议**：建议保留3位小数，以获得足够的精度

5. **重启生效**：修改 `config.yaml` 后需要重启程序才能生效

## 🔍 验证零位设置

设置零位后，可以通过以下方式验证：

1. **观察站立姿态**：切换到模式'2'（站立模式），机器人应该保持你设置的零位姿态

2. **检查关节位置输出**：在站立模式下，`joint_pos` 应该接近 `ref_joint_act` 的值

3. **检查观测向量**：在 `get_observation()` 中，`joint_pos - ref_joint_act` 应该接近零

## 💡 快速设置脚本

你也可以创建一个简单的脚本来帮助设置零位：

```bash
#!/bin/bash
# set_zero_position.sh

# 从日志中提取最新的关节位置
JOINT_POS=$(grep "Q: \[" qmini_log.log | tail -1 | sed 's/Q: \[ //' | sed 's/ \]//')

if [ -n "$JOINT_POS" ]; then
    echo "找到关节位置: $JOINT_POS"
    echo ""
    echo "请将以下内容复制到 config.yaml 的 ref_joint_act 字段："
    echo "ref_joint_act: [ $JOINT_POS ]"
else
    echo "未找到关节位置，请确保程序正在运行并已输出关节位置"
fi
```
