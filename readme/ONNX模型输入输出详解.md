# ONNX模型输入输出详解

本文档详细说明ONNX模型的43维观测量和12维输出量的具体含义。

---

## 📊 一、模型输入：观测向量（Observation）

### 1.1 单帧观测向量（43维）

模型每次接收**3帧历史观测**的堆叠，形成**129维**输入（43 × 3 = 129）。

**单帧观测向量（43维）的详细组成**：

| 维度索引 | 维度范围 | 变量名 | 含义 | 单位/范围 | 备注 |
|---------|---------|--------|------|----------|------|
| **1. 目标命令（2维）** |
| 0 | `[0]` | `target_command[0]` | **期望前进速度** (vx_cmd) | m/s | 由摇杆输入映射得到，范围：vx_min ~ vx_max |
| 1 | `[1]` | `target_command[1]` | **期望转向角速度** (yr_cmd) | rad/s | 由摇杆输入映射得到，范围：-yr_max ~ yr_max |
| **2. 基座姿态（2维）** |
| 2 | `[2]` | `base_rpy[0]` | **基座横滚角** (roll) | rad | 机器人左右倾斜角度 |
| 3 | `[3]` | `base_rpy[1]` | **基座俯仰角** (pitch) | rad | 机器人前后倾斜角度 |
| **3. 基座角速度（3维）** |
| 4 | `[4]` | `base_rpy_rate[0] * 0.5` | **横滚角速度** (roll_rate) | rad/s | 缩放因子0.5 |
| 5 | `[5]` | `base_rpy_rate[1] * 0.5` | **俯仰角速度** (pitch_rate) | rad/s | 缩放因子0.5 |
| 6 | `[6]` | `base_rpy_rate[2] * 0.5` | **偏航角速度** (yaw_rate) | rad/s | 缩放因子0.5 |
| **4. 关节位置偏差（10维）** |
| 7-16 | `[7:17]` | `joint_pos[i] - ref_joint_act[i]` | **关节位置相对参考位置的偏差** | rad | 10个关节（NUM_ACTUAT_JOINTS=10）<br>表示当前关节位置与站立姿态参考位置的差值 |
| **5. 关节速度（10维）** |
| 17-26 | `[17:27]` | `joint_vel[i] * 0.1` | **关节角速度（缩放）** | rad/s | 缩放因子0.1<br>10个关节的速度信息 |
| **6. 关节位置误差（10维）** |
| 27-36 | `[27:37]` | `joint_act[i] - joint_pos[i]` | **目标位置与实际位置的误差** | rad | 10个关节<br>表示期望位置与实际位置的差值（用于位置控制反馈） |
| **7. 相位信息（4维）** |
| 37 | `[37]` | `sin(_pm_phase[0]) * static_flag` | **左腿相位sin值** | 无单位 | 仅在运动时有效（static_flag=1）<br>编码左腿在步态周期中的位置 |
| 38 | `[38]` | `cos(_pm_phase[0]) * static_flag` | **左腿相位cos值** | 无单位 | 仅在运动时有效 |
| 39 | `[39]` | `sin(_pm_phase[1]) * static_flag` | **右腿相位sin值** | 无单位 | 仅在运动时有效<br>编码右腿在步态周期中的位置 |
| 40 | `[40]` | `cos(_pm_phase[1]) * static_flag` | **右腿相位cos值** | 无单位 | 仅在运动时有效 |
| **8. 频率信息（2维）** |
| 41 | `[41]` | `(pm_f[0] * 0.3 - 1) * static_flag` | **左腿步态频率** | 无单位（归一化） | 仅在运动时有效<br>表示左腿步态的当前频率 |
| 42 | `[42]` | `(pm_f[1] * 0.3 - 1) * static_flag` | **右腿步态频率** | 无单位（归一化） | 仅在运动时有效<br>表示右腿步态的当前频率 |

### 1.2 观测向量堆叠（129维输入）

模型实际输入是**3帧历史观测**的堆叠：

```
输入格式：[obs_t-2, obs_t-1, obs_t]
         └─43维─┘ └─43维─┘ └─43维─┘
         总维度 = 43 × 3 = 129维
```

**堆叠的作用**：
- 提供时序信息，让模型理解运动趋势
- 帮助模型判断加速/减速、稳定性等动态特性
- 相当于给模型提供"短期记忆"

**堆叠更新机制**（滑动窗口）：
```cpp
// 每次控制循环：
obs_stack.erase(obs_stack.begin());  // 移除最旧的一帧
obs_stack.push_back(obs);            // 添加当前观测
```

### 1.3 观测值范围限制

所有观测值会被限制在 **[-3, 3]** 范围内，防止异常值影响模型推理：
```cpp
obs = obs.cwiseMax(-3.).cwiseMin(3.);
```

### 1.4 关键变量说明

#### `static_flag`（运动标志）
```cpp
if (sqrt(pow(target_command(0), 2) + pow(target_command(1), 2)) < 0.15)
    static_flag = 0.f;  // 静止状态：相位和频率信息为0
else
    static_flag = 1.f;  // 运动状态：相位和频率信息有效
```

**作用**：
- 当机器人静止时（速度命令<0.15），相位和频率信息设为0
- 只在运动时提供步态相位和频率信息，让模型专注控制

#### `_pm_phase`（相位角）
- 范围：[0, 2π)
- 表示左右腿在步态周期中的位置
- 使用sin/cos编码，避免0和2π的不连续性

#### `ref_joint_act`（参考关节位置）
- 10维向量，表示机器人的"站立姿态"参考位置
- 用于计算关节位置偏差，让模型理解当前姿态与标准姿态的差异

## 🎯 二、模型输出：动作向量（Action）

### 2.1 原始输出（12维，范围[-1, 1]）

ONNX模型直接输出**12维**向量，值域为**[-1, 1]**（tanh激活函数输出）。

| 维度索引 | 维度范围 | 含义 | 说明 |
|---------|---------|------|------|
| **相位频率（2维）** |
| 0 | `[0]` | **左腿相位频率增量** | 控制左腿步态的相位频率变化 |
| 1 | `[1]` | **右腿相位频率增量** | 控制右腿步态的相位频率变化 |
| **关节位置增量（10维）** |
| 2-11 | `[2:12]` | **10个关节的位置增量** | 控制Qmini的10个关节运动<br>对应关节索引：0-9 |

**注意**：这是**原始输出**，需要进行转换才能用于实际控制。

### 2.2 动作转换（transform函数）

模型输出需要经过转换才能使用：

#### 步骤1：归一化到[0, 1]
```cpp
auto net = (data.array() + 1.) / 2.;
```
- 将[-1, 1]映射到[0, 1]

#### 步骤2：线性映射到实际范围
```cpp
action_increment(i) = net(i) * (high - low) + low;
```

**不同维度的映射范围**（来自`config.yaml`的`act_inc_high`和`act_inc_low`）：

| 动作维度 | 配置索引 | 下限 (low) | 上限 (high) | 实际范围 | 单位 |
|---------|---------|-----------|------------|---------|------|
| **维度0-1（相位频率）** | `[0]` | 0.5 | 3.5 | 0.5 ~ 3.5 | Hz |
| **维度2-11（关节增量）** | `[1]` | -15.0 | 15.0 | -15.0 ~ 15.0 | rad/s |

### 2.3 转换后的动作（12维）

|---------|--------|------|------|------|------|

| 0 | `pm_f[0]` | **左腿相位频率** | 0.5 ~ 3.5 | Hz | 控制左腿步态的节奏频率 |

### 2.4 动作应用（joint_increment_control函数）

转换后的动作会被应用到机器人控制中：

```cpp
void RLController::joint_increment_control(Matrix<float, Dynamic, 1> increment) {
    // 1. 提取相位频率（前2维）
    pm_f = increment.segment(0, NUM_LEGS);  // NUM_LEGS = 2
    
    // 2. 根据频率更新相位
    compute_pm_phase(pm_f);
    
    // 3. 更新10个关节的目标位置（后10维）
    joint_act.segment(0, NUM_ACTUAT_JOINTS) += 
        increment.segment(NUM_LEGS, NUM_ACTUAT_JOINTS) * _rl_time_step;
    // _rl_time_step ≈ 0.015s（15ms控制周期）
    
    // 4. 限制关节位置在允许范围内
    joint_act = joint_act.cwiseMax(act_pos_low).cwiseMin(act_pos_high);
}
```

**关键步骤**：
1. **相位频率**（维度0-1）用于更新步态相位角`_pm_phase`
2. **关节增量**（维度2-11）乘以时间步长后累加到目标关节位置`joint_act`
3. 最终目标位置会被限制在`act_pos_low`和`act_pos_high`之间

### 2.5 关节映射

**Qmini机器人有10个关节**，对应10个可控制关节：

| 关节索引 | 关节名称/位置 | 说明 |
|---------|-------------|------|
| 0 | 左前髋关节 | 控制左前腿的髋部运动 |
| 1 | 左前膝关节 | 控制左前腿的膝部运动 |
| 2 | 右前髋关节 | 控制右前腿的髋部运动 |
| 3 | 右前膝关节 | 控制右前腿的膝部运动 |
| 4 | 左后髋关节 | 控制左后腿的髋部运动 |
| 5 | 左后膝关节 | 控制左后腿的膝部运动 |
| 6 | 右后髋关节 | 控制右后腿的髋部运动 |
| 7 | 右后膝关节 | 控制右后腿的膝部运动 |
| 8 | 腰部关节 | 控制腰部的左右摆动 |
| 9 | 其他关节 | 根据实际机器人配置 |

**注意**：具体的关节命名和位置可能因机器人型号而异，这里只是示例。

## 📈 三、数据流示例

### 示例1：模型推理完整流程

假设当前状态：
- 目标命令：`target_command = [0.3, 0.1]`（前进0.3 m/s，右转0.1 rad/s）
- 基座姿态：`base_rpy = [0.05, 0.1, 0.0]`（轻微前倾）
- 关节状态：10个关节的位置和速度
- 步态相位：`_pm_phase = [0.5, 1.2]`

**步骤1：构建观测向量（43维）**
```cpp
obs = [
    0.3, 0.1,                    // [0:2]   目标命令
    0.05, 0.1,                   // [2:4]   基座姿态
    0.01, 0.02, 0.0,            // [4:7]   基座角速度（已缩放）
    -0.1, 0.2, -0.05, ...,      // [7:17]  关节位置偏差（10维）
    0.5, -0.3, 0.2, ...,        // [17:27] 关节速度（10维，已缩放）
    0.05, -0.02, 0.1, ...,      // [27:37] 关节位置误差（10维）
    0.48, 0.88, 0.93, 0.36,     // [37:41] 相位信息（sin/cos，已缩放）
    0.14, 0.23                   // [41:43] 频率信息（已归一化）
]
```

**步骤2：堆叠3帧历史（129维）**
```cpp
observation = [
    obs_t-2,  // 43维（2帧前的观测）
    obs_t-1,  // 43维（1帧前的观测）
    obs_t     // 43维（当前观测）
]
// 总维度 = 43 × 3 = 129
```

**步骤3：ONNX推理**
```cpp
net_out = onnxInference.inference(motion_session, observation);
// 输出：[-0.3, 0.5, 0.2, -0.1, 0.4, 0.1, -0.2, 0.3, -0.1, 0.2, 0.0, -0.1]
//      [频率左,频率右,关节0,关节1,关节2,关节3,关节4,关节5,关节6,关节7,关节8,关节9]
```

**步骤4：动作转换**
```cpp
// 原始输出：[-0.3, 0.5, 0.2, -0.1, 0.4, ...]
// ↓ transform()
// 转换后：
action_increment = [
    1.1,      // 左腿频率：(-0.3+1)/2*(3.5-0.5)+0.5 = 1.1 Hz
    2.75,     // 右腿频率：(0.5+1)/2*(3.5-0.5)+0.5 = 2.75 Hz
    4.5,      // 关节0增量：(0.2+1)/2*(15-(-15))+(-15) = 4.5 rad/s
    -6.0,     // 关节1增量：(-0.1+1)/2*30-15 = -6.0 rad/s
    9.0,      // 关节2增量：(0.4+1)/2*30-15 = 9.0 rad/s
    ...       // 其他7个关节
]
```

**步骤5：应用动作**
```cpp
// 更新相位频率
pm_f = [1.1, 2.75];
compute_pm_phase(pm_f);  // 根据频率更新相位角

// 更新关节目标位置
joint_act[0] += 4.5 * 0.015;    // 关节0目标位置增加 0.0675 rad
joint_act[1] += (-6.0) * 0.015; // 关节1目标位置减少 0.09 rad
joint_act[2] += 9.0 * 0.015;    // 关节2目标位置增加 0.135 rad
// ... 其他关节

// 限制在允许范围内
joint_act = joint_act.cwiseMax(act_pos_low).cwiseMin(act_pos_high);
```

## 🎯 六、总结

### 输入（129维）
- **单帧观测**：43维
  - 目标命令：2维
  - 基座状态：5维（姿态2维 + 角速度3维）
  - 关节状态：30维（位置偏差10维 + 速度10维 + 位置误差10维）
  - 步态信息：6维（相位4维 + 频率2维）
- **历史堆叠**：3帧 × 43维 = 129维

### 输出（12维）
- **原始输出**：12维，范围[-1, 1]
- **转换后**：
  - 相位频率：2维（0.5 ~ 3.5 Hz）
  - 关节增量：10维（-15.0 ~ 15.0 rad/s）

### 关键特性
1. **时序感知**：3帧历史堆叠提供运动趋势信息
2. **状态编码**：相位使用sin/cos编码，避免不连续性
3. **增量控制**：输出是增量而非绝对位置，便于平滑控制
4. **范围限制**：所有观测和动作都有明确的上下限，保证稳定性
