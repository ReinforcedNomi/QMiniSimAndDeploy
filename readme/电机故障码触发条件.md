# 电机故障码触发条件

## 概述

本文档详细说明 GO-M8010-6 电机的故障码（`merror`）定义及其触发条件。

---

## 一、故障码定义

根据 `motor_msg_GO-M8010-6.h` 文件定义：

```cpp
uint8_t  MError :3;  // 电机错误标识（3位，取值0-7）
```

### 故障码列表

| 故障码 | 含义 | 说明 |
|--------|------|------|
| **0** | **正常** | 电机运行正常，无故障 |
| **1** | **过热** | 电机温度超过保护阈值 |
| **2** | **过流** | 电机电流超过保护阈值 |
| **3** | **过压** | 电机电压超过保护阈值 |
| **4** | **编码器故障** | 编码器读取异常或通信故障 |
| **5** | **保护/过载** | 电机过载保护或状态异常（常见于电机保护状态） |
| **6-7** | **保留** | 未定义的故障码 |

## 二、各故障码触发条件详解

### 2.1 故障码 1：过热保护

**触发条件**：
- 电机温度达到或超过 **90°C**
- 温度传感器读取值：`temp >= 90`（或接近90°C）

**原因分析**：
1. **持续大负载运行**：高 kp/kd 值 + 大位置误差导致持续大电流
2. **环境温度过高**：机器人工作环境温度高
3. **散热不良**：电机散热通道堵塞或风扇故障
4. **机械阻力过大**：关节卡滞、摩擦增大

**防护措施**：
- ✅ 已实现：力矩保护（`torque_limit`，默认20.0 N·m）
- ✅ 建议：监控温度值，在80°C时降低kp/kd
- ✅ 建议：检查机械润滑和关节灵活性

---

### 2.2 故障码 2：过流保护

**触发条件**：
- 电机实际电流超过硬件保护阈值
- 通常由力矩过大引起（力矩 ≈ 电流 × 力矩常数）

**原因分析**：
1. **位置误差过大**：目标位置与实际位置差距大，PD控制器输出大力矩
   ```
   力矩 = kp × 位置误差 + kd × 速度误差
   ```
2. **kp/kd 值过大**：配置的刚度/阻尼系数过大
3. **速度误差过大**：快速运动时速度误差大，kd产生大阻尼力矩
4. **堵转**：关节被卡住，位置误差持续存在，力矩持续增大

**防护措施**：
- ✅ 已实现：力矩保护（`torque_limit: 20.0 N·m`）
- ✅ 已实现：位置限位（`act_pos_low` / `act_pos_high`）
- ⚠️ 缺失：位置误差监控和限制
- ⚠️ 缺失：动态调整 kp/kd（位置误差大时降低）

**计算方法**：
```cpp
// 当前代码中的力矩保护检查
if (std::abs(joint_tau[i]) > torque_limit[i]) {
    // 超过阈值持续0.5秒后触发保护
}
```

### 2.3 故障码 3：过压保护

**触发条件**：
- 电机供电电压超过安全范围（通常 > 48V 或硬件设定阈值）
- 电压传感器检测到异常高电压

**原因分析**：
1. **电源问题**：电源输出电压异常或波动
2. **硬件故障**：电源管理模块故障
3. **反向电动势过大**：电机高速运转时产生的反电动势过高

**防护措施**：
- ⚠️ 硬件层面保护（代码层面难以直接控制）
- ✅ 建议：监控电源电压，异常时报警

---

### 2.4 故障码 4：编码器故障

**触发条件**：
- 编码器读取异常（位置数据突变、跳跃）
- 编码器通信故障（数据包丢失、CRC错误）
- 编码器硬件故障

**原因分析**：
1. **通信干扰**：串口通信受到电磁干扰
2. **硬件连接**：编码器线缆松动、接触不良
3. **编码器损坏**：编码器硬件故障
4. **通信超时**：串口通信超时（当前超时时间：50ms）

**防护措施**：
- ✅ 已实现：串口通信超时检测（50ms）
- ⚠️ 缺失：编码器数据合理性检查（位置突变检测）
- ✅ 建议：检查串口连接和线缆

**代码位置**：

### 2.5 故障码 5：保护/过载状态

**触发条件**：
- 电机进入保护状态（过载、过热等）
- 电机模式切换异常
- 通信或状态同步问题
- 电机初始化未完成

**原因分析**：
根据实际使用情况和网络资料，错误码5通常表示：
1. **电机过载保护**：虽然官方定义为"保留"，但实际可能是过载保护的另一种形式
2. **电机过热保护**：可能不是错误码1的标准过热，而是接近过热阈值的保护状态
3. **位置/速度保护**：位置或速度超出安全范围
4. **通信异常**：电机与控制器的通信状态不同步
5. **模式切换问题**：电机在FOC模式切换时的中间状态
6. **初始化未完成**：电机未完全初始化完成

**常见现象**：
- 多个关节同时报错误码5（如日志中的Joint 0, 1, 4, 7, 8, 9）
- 扭矩输出接近0（电机处于保护状态，限制输出）
- 位置响应迟缓或无法响应目标位置

**防护措施**：
- ✅ 检查电机负载是否过大
- ✅ 检查电机散热情况
- ✅ 检查通信连接是否稳定（串口通信）
- ✅ 尝试重启电机或重新初始化
- ✅ 检查电机模式设置是否正确（FOC模式）
- ✅ 检查kp/kd参数是否过大导致电机保护

**排查步骤**：
1. **检查负载**：确认电机负载在额定范围内，减小位置误差
2. **检查温度**：如果电机温度接近90°C，可能是过热前兆
3. **检查通信**：确认串口通信正常，无丢包或超时
4. **重启电机**：尝试断电重启或重新初始化电机
5. **检查模式**：确认电机模式设置正确（MotorMode::FOC）
6. **降低kp/kd**：如果错误码5持续出现，尝试降低kp/kd值

**代码位置**：
```cpp
// Motor_thread.hpp: ConfigureMotorCommand
cmd.mode = queryMotorMode(MotorType::GO_M8010_6, MotorMode::FOC);
```

## 五、故障排查流程

### 故障码 = 1（过热）

1. **立即停止运动**，降低负载
2. **检查温度**：查看 `temp` 值，确认是否真的过热
3. **降低 kp/kd**：临时降低刚度/阻尼系数
4. **检查环境**：确保通风良好，散热正常
5. **等待冷却**：温度降至安全范围（< 80°C）后再启动

### 故障码 = 2（过流）

1. **检查力矩**：查看 `joint_tau` 是否超过 `torque_limit`
2. **检查位置误差**：计算 `joint_act - joint_pos`，误差是否过大
3. **降低 kp/kd**：减小刚度/阻尼系数
4. **检查机械**：确认关节是否卡滞
5. **检查限位**：确认目标位置是否在限位范围内

### 故障码 = 3（过压）

1. **检查电源**：使用万用表测量电机供电电压
2. **检查电源管理**：确认电源管理模块正常工作
3. **硬件检查**：如持续过压，可能是硬件故障

### 故障码 = 4（编码器故障）

1. **检查串口连接**：确认线缆连接牢固
2. **检查通信**：查看串口通信是否正常（是否有超时）
3. **检查位置数据**：观察 `joint_pos` 是否有突变
4. **重启电机**：尝试重启电机或重新校准编码器

## 七、总结

| 故障码 | 触发条件 | 严重程度 | 当前防护 | 建议措施 |
|--------|---------|---------|---------|---------|
| **0** | 正常 | - | - | - |
| **1** | 温度 ≥ 90°C | 高 | ⚠️ 无 | 添加温度监控，>80°C预警 |
| **2** | 电流过大 | 高 | ✅ 力矩保护 | 添加位置误差监控 |
| **3** | 电压过高 | 中 | ⚠️ 无 | 硬件层面保护 |
| **4** | 编码器异常 | 高 | ⚠️ 无 | 添加故障码检查 |

**关键建议**：
1. ⚠️ **立即添加故障码监控**：在 `RecordMotorState` 中检查 `merror`
2. ⚠️ **添加温度监控**：温度>80°C时降低kp/kd或报警
3. ✅ **已实现力矩保护**：继续使用并调整阈值
4. ⚠️ **添加位置误差监控**：误差过大时自动降低kp/kd
